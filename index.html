NETINSIGHT APT Repository

This page is the public APT distribution for NETINSIGHT, the enterprise NetFlow / sFlow / IPFIX analytics platform.

Install on Ubuntu 22.04 (jammy)

wget --tries=5 --waitretry=10 https://dkg-netinsight.github.io/apt-repo/pool/main/n/netinsight/netinsight-release_1.0.0-85+ubuntu22.04_all.deb
dpkg -i netinsight-release_1.0.0-85+ubuntu22.04_all.deb
apt update
apt install -y netinsight

Install on Ubuntu 24.04 (noble)

wget --tries=5 --waitretry=10 https://dkg-netinsight.github.io/apt-repo/pool/main/n/netinsight/netinsight-release_1.0.0-85+ubuntu24.04_all.deb
dpkg -i netinsight-release_1.0.0-85+ubuntu24.04_all.deb
apt update
apt install -y netinsight

Signing

All Release / InRelease files are signed with the NETINSIGHT release subkey 1A1420ACE40DC218 (master 477C1561698EB0C329C3C6DD02E2D963F0BC0D33, signing subkey expires 2028-05-08). The keyring binary is shipped inside netinsight-release_*.deb; apt enforces it via [signed-by=...].
